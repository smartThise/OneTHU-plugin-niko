# 一键发送 niko 烂梗（OneTHU 插件）

> author: **smartThis** · 个人娱乐插件 · **与 OneTHU 官方无关，勿上架插件市场**
> v0.1.0 · 仅供搞笑，请勿刷屏

从 [sb6657.cn（玩机器烂梗收集）](https://sb6657.cn/) 随手捞一条烂梗，用你的斗鱼登录态，
经斗鱼弹幕 WebSocket 协议直接发进直播间（默认玩机器的 6657 房间）。

## 安装

**方式 A · 粘贴安装**：OneTHU → 设置 → 插件 → 安装插件 → 粘贴代码，把 `plugin.js`
全文粘进去 → 安装 → 逐项确认权限（`外部网络请求`、`显示提示`）。

**方式 B · GitHub 仓库直装**（把本仓库推到你个人 GitHub 后）：
插件页 → 安装插件 → GitHub 仓库 → 输入 `你的用户名/OneTHU-plugin-niko`。

## 配置（设置 → 插件 → 本插件卡片 → 设置）

| 设置项 | 说明 |
|---|---|
| 斗鱼 Cookie | **发送必需**。须含 `dy_did` / `acf_uid` / `acf_stk` / `acf_ltkid` 四个字段 |
| 目标房间号 | 默认 `6657`（玩机器） |
| 最小发送间隔 | 默认 30s，防手滑刷屏 |

**获取 Cookie**：浏览器登录 bo的鱼（其实 douyu.com）→ F12 → 网络 → 任选一条请求 →
请求头里把整串 `Cookie: ...` 复制 → 粘进插件设置。登录失效（弹不出回显 / 登录超时）就重新复制。

## 「发不出去」的真相（都替你查过了）

1. **没登录**：纯 WS 协议不强制登录，但**发言必须登录态**（Cookie 四字段缺一不可，插件会点名缺哪个）；
2. **等级墙**：6657 房间有斗鱼等级门槛，低等级号的弹幕会被**静默吞掉**（发出无报错、不上墙）。
   所以插件不拿「发送成功」糊弄你——发送后监听 10 秒**本账号弹幕回显**：
   - ✅ 收到回显 = 真的上墙了；
   - ⚠️ 没回显 = 大概率被等级墙 / 风控拦截，插件会如实告诉你；
3. **屏蔽词**：发出前会用 sb6657 收录的斗鱼屏蔽词库预检，中了会在结果里标注「可能被吞」；
4. **is_illegal=1**：登录响应里若标记账号受限会显式报出。

若显示「回显确认」但房间里没看到，那就是被主播/房管折叠或过滤了自己看不出来，插件没说谎。

## 技术备忘

- 烂梗接口：`api.hguofichp.cn`（sb6657 后端，公开 GET：`getRandOne` / `hotBarrageOf24H` / `getShieldWordDict`）
- 斗鱼协议：`wss://wsproxy.douyu.com:6673` 登录 → `msgrepeaterproxylist` 拿弹幕服务器 →
  `wss://danmuproxy.douyu.com:850x` 登录进房 → `chatmessage` 帧发送。
  编解码（12 字节帧头 + STT 转义）与 `vk = md5(rt + secret + dy_did)` 与
  [ordinaryroad-live-chat-client](https://github.com/zhziyu/ordinaryroad-live-chat-client) 同源，本机实测全链路打通。
- Cookie 只保存在 OneTHU 插件私有设置里，只用于斗鱼登录 WS 握手，不回传任何第三方。
